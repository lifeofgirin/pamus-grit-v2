# Pamus Grit v2 - v14

## PWA 설치형

추가:
- manifest.webmanifest
- Pamus Grit 앱 아이콘
- standalone 실행
- iPhone 홈 화면 추가 대응
- Android/Chrome 앱 설치 대응
- 서비스워커 등록
- 정적 파일 캐시
- API는 항상 네트워크 우선 처리해 학원 데이터 stale 방지
- 모바일 safe-area 대응

설치:
- iPhone Safari → 공유 → 홈 화면에 추가
- Android Chrome → 메뉴 → 앱 설치 / 홈 화면에 추가

주의:
- 오프라인에서 학원 데이터 저장/수정까지 지원하는 버전은 아님.
- 네트워크가 있어야 출결/진도/학생관리 등 서버 기능이 정상 작동함.

SQL 추가 없음.
