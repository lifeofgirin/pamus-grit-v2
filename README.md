# Pamus Grit v2 - v16

## BAND 일정 등록 도우미

반별 화면에 `BAND 일정` 버튼 추가.

기능:
- 해당 주의 날짜 선택
- 그 날짜의 숙제 자동 수집
- 숙제를 작성한 선생님 자동 감지
- 일정 제목 자동 생성
  예: `컬럼비아A[May,Han]숙제`
- 선생님 BAND 표기 자동 변환
  - 메이T → May
  - 한T → Han
  - 리나T → Rina
  - Adriana T → Adriana
  - 기타 주요 선생님 포함
- 일정 제목 직접 수정 가능
- 숙제 내용 직접 수정 가능
- 제목 + 숙제 한 번에 클립보드 복사
- 모바일에서 BAND 앱 열기
- PC에서는 BAND 웹 열기

중요:
BAND 공개 API/공식 scheme에는 외부 웹앱에서
BAND ‘일정’을 직접 생성하는 기능이 제공되지 않아,
복사 → BAND 열기 → 모밴드 일정 추가 → 붙여넣기 방식으로 동작.

추가 SQL 없음.
