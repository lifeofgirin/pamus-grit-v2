# Pamus Grit v2 - v4

기능
- 4자리 PIN 로그인
- 관리자 / 선생님 권한 분리
- 오늘 강의실별 시간표
- 월~금 주간 시간표
- 지난주 / 이번주 / 다음주 이동
- 주간 수업 카드 클릭 후 해당 날짜 수업 작성
- 진도 / 숙제 / 특이사항
- 출석 / 지각 / 결석 / 보강
- 전체 출석
- 저장 후 완료 상태 즉시 갱신

추가 SQL은 필요 없습니다.

Vercel 환경변수는 기존 그대로 유지합니다.
- NEXT_PUBLIC_SUPABASE_URL
- NEXT_PUBLIC_SUPABASE_PUBLISHABLE_KEY
- SUPABASE_SECRET_KEY
