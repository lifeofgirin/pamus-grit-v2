# Pamus Grit v2 - v13

## 학생 상세 / 상담용 이력

관리자 1004 → 학생관리 → 학생 클릭:
- 기존 학생 정보 수정 유지
- 현재 반
- 주담당 선생님
- 학교 / 학년
- 최근 출결 통계
  - 출석
  - 지각
  - 결석
  - 보강
- 최근 출결 30건
- 보강 이력
  - 출결에서 `보강` 처리된 기록
  - 자유보강 제목에 학생 이름이 포함된 기록
- 현재 반 최근 진도 / 숙제 / 메모

주의:
- 자유보강은 현재 makeup_lessons에 student_id가 없기 때문에
  제목에 학생 이름이 포함된 경우만 학생 상세에 자동 연결됨.
- 출결의 `보강` 기록은 student_id가 있어 정확히 연결됨.

추가 SQL 없음.
