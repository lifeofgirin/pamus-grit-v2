# Pamus Grit v2 - v17

## 반관리 → 기간별 기본 시간표

관리자 1004 → 반관리 → 반 클릭에서:
- 기본 시간표 확인
- 적용 시작일 선택
- 요일 / 시작시간 / 종료시간 / 과목 / 강의실 / 선생님 수정
- 수업 추가
- 수업 삭제
- 지정 날짜부터 새 기본 시간표 적용

예:
- 8/16까지 방학 오전 시간표 유지
- 적용 시작일을 8/17로 선택
- 개학 후 오후 시간표 작성
- `이 날짜부터 시간표 적용` 저장
→ 8/16 이전 기록/시간표는 그대로 유지
→ 8/17부터 새 시간표 사용

구조:
- schedules.valid_from / valid_to 추가
- 기존 시간표는 valid_from=2000-01-01
- 새 버전 저장 시 이전 버전은 적용일 전날까지 종료
- 당일변경/휴강(daily_schedule_changes)은 기존 기능 그대로 유지
