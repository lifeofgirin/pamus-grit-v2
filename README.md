# Pamus Grit v2 - v18.3.4

## 휴강/공강 운영 개선

1. 휴강 처리 시 시간표에서 숨김
- 당일변경에서 상태를 `휴강`으로 저장하면
  해당 날짜의 오늘/주간 시간표에서 카드가 보이지 않습니다.
- 기본 시간표 자체는 삭제되지 않습니다.
- 다음 주 정규 수업에는 영향이 없습니다.

2. 모바일 관리자 당일변경
- PC: 기존처럼 클릭 = 수업 작성 / 우클릭 = 당일변경
- 모바일 관리자: 수업 카드를 탭하면 바로 당일변경 창이 열립니다.
- 휴강/시간/강의실/과목/선생님 변경 가능

3. 휴강 후 빈 시간에 다른 수업 넣기
- 휴강 저장 직후 `빈 시간에 다른 수업을 넣을까요?` 확인창 표시
- 취소 → 그냥 공강 유지
- 확인 → 대체수업 추가 창
- 기존 반 선택 가능
- 휴강한 날짜/시간/강의실 자동 입력
- 반 선택 시 가능한 경우 기존 담당선생님/과목 자동 참고
- 필요하면 선생님/시간/강의실 직접 수정 후 등록
- 대체수업은 기존 자유 보강 시스템을 활용하여 초록색 수업 카드로 표시

SQL 추가 없음.
