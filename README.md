## 학생관리

관리자 1004 전용 `학생관리` 탭:
- 전체 학생 목록
- 이름 / 학교 / 학년 / 반 검색
- 학생 정보 수정
- 소속반 변경
- 재원 / 휴원 / 퇴원 상태 변경
- 학생 추가
- 학생 삭제
- 목록 스크롤
- 모바일 가로 스크롤 대응
- 생년월일 컬럼이 존재하면 입력/수정 지원
- 기존 students / classes 테이블 사용

주의:
- 출결 등 다른 기록이 연결된 학생은 DB 관계 설정에 따라 삭제가 거부될 수 있음.
  이 경우 삭제보다 상태를 `퇴원`으로 변경하는 방식 권장.
