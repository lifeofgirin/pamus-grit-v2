## 1004 관리자 전용 요일별 강의실 시간표

새 관리자 탭:
`요일시간표`

구성:
- 월 / 화 / 수 / 목 / 금 선택
- 세로 시간축: 13:00 ~ 20:00
- 가로 강의실:
  101 / 102 / 103 / 204 / 205 / 206 / 207 / 208
- 수업은 실제 시작/종료 시간 길이에 맞춰 카드 표시
- 반 / 과목 / 선생님 표시
- 추가수업도 함께 표시
- 휴강은 기존 정책대로 숨김
- 학원 일정 표시
- 지난주 / 이번주 / 다음주 이동

권한:
- 관리자(1004) 화면에만 탭 표시
- 선생님 계정에는 탭 미표시

수업 카드:
- PC 클릭: 기존 수업 작성
- PC 우클릭: 기존 당일 변경/휴강
- 모바일 탭: 기존 관리자 모바일 당일 변경 로직 사용
