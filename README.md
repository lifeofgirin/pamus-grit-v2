# Pamus Grit v2 - v17.1

## 반관리 시간 편집 오류 수정

원인:
- 수업 행의 React key에 시작 시간을 사용
- 시작 시간을 변경하는 순간 key가 바뀌어 해당 행이 통째로 재생성됨
- 동시에 시간순 자동 정렬까지 실행되어 모바일에서 새로고침/오류처럼 보일 수 있었음

수정:
- 각 수업 행에 고정 client id 부여
- 시간/요일/과목/강의실/선생님을 바꿔도 같은 행 유지
- 편집 중 실시간 자동 정렬 제거
- 저장 전 시작/종료 시간 유효성 검사 추가

DB:
- 17차 SQL을 이미 실행했다면 추가 SQL 없음
- 아직 안 했다면 기존 17차 SQL만 1회 실행
