# Pamus Grit v2 - v5.3

## 관리자 주간 가독성 개선
- 관리자 1004 주간 화면에 선생님 필터 추가
- 소피아T / 에릭T / 리나T / 한T 등 버튼으로 즉시 전환
- 선택한 선생님의 월~금 수업만 간단 표시
- 시간 / 반 / 과목 / 강의실 중심의 압축 카드
- 전체 버튼을 누르면 기존 전체 주간도 확인 가능
- 기본 진입은 첫 번째 선생님으로 설정해 전체 수업이 한꺼번에 쏟아지지 않게 함
