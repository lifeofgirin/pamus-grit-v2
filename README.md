# Pamus Grit v2 - v18.3.6

## 추가수업도 일반 수업처럼 작성

주간에서 `+ 수업 추가`로 만든 당일수업을 이제 클릭하면 일반 수업과 동일한 작성창이 열립니다.

가능:
- 진도 작성
- 숙제 작성
- 특이사항 작성
- 해당 반 학생 출결
- 전체 출석
- 저장

또한 반별 주간 · 진도/숙제 요약에도 추가수업에서 작성한 진도/숙제가 같이 표시됩니다.

### 중요
이번 버전은 DB 컬럼/테이블이 추가되므로 SQL을 먼저 1회 실행해야 합니다.

`PamusGrit_v2_18_3_6차_추가수업기록_DB추가.sql`

그 뒤 전체 코드 교체 → GitHub push → Vercel Production 배포.

기존 정규수업 데이터에는 영향 없습니다.
