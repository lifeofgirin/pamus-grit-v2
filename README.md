# Pamus Grit v2 - v7

## 오늘 업무 대시보드

모든 선생님:
- 오늘 / 업무 / 주간 / 반별
- 업무 탭에서 미작성 수업만 표시
- 진도 미작성
- 숙제 미작성
- 출결 미완료
- 수업 클릭 시 바로 작성창
- 저장하면 업무 현황 즉시 갱신

관리자 1004:
- 선생님별 오늘 업무 현황
- 선생님별 전체 수업 / 완료 / 미완료
- 진도 / 숙제 / 출결 미완료 개수
- 미완료 수업 클릭 후 바로 작성 가능

기존 기능 유지:
- 관리자 일간 강의실별
- 선생님 일간 시간순
- 자유 보강
- 휴강 / 당일변경
- 관리자 선생님별 주간
- 반별 주간 + 진도/숙제 통합 요약
- 복사 기능
