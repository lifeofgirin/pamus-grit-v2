# Pamus Grit v2 - v18.3

## 모바일 반별주간 카드 간소화
모바일에서만 수업카드를 아래처럼 표시:
- 시작시간
- 강의실
- 선생님

과목은 모바일 카드에서 숨김.
카드 클릭 시 기존 상세 정보는 그대로 확인 가능.
PC에서는 기존처럼 시작~종료시간/과목/강의실/선생님 상세 표시 유지.

## 선생님 화면 한/영 전환
- 선생님 계정에만 `한국어 / English` 토글 추가
- 선택값은 localStorage에 저장되어 해당 휴대폰에서 유지
- 주요 메뉴/주간/반별/복사/빈수업/요약 등 고정 UI를 영어로 전환
- 선생님이 직접 작성한 진도/숙제 원문은 번역하지 않음
- 관리자 화면은 기존 한국어 유지

SQL 추가 없음.
