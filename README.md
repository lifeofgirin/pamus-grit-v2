# Pamus Grit v2 - v18.3.5

## 주간 시간표에서 당일 수업 추가

관리자와 모든 선생님 계정:
- 주간 화면에 `+ 수업 추가`
- 날짜 선택
- 반 선택
- 시작/종료 시간
- 강의실
- 과목
- 담당 선생님
- 메모
- 저장

### 선생님 계정
- 자신이 접근 가능한 반만 선택
- 담당 선생님은 로그인한 본인으로 서버에서 자동 저장
- 영어 UI에서는 Add Class로 표시

### 관리자
- 전체 반 선택 가능
- 담당 선생님 선택 가능

### 중요한 점
- 정규 기본 시간표(schedules)는 수정하지 않음
- 선택한 날짜 하루에만 추가됨
- 기존 makeup_lessons 테이블을 안정적으로 재사용
- 오늘/주간 시간표에 즉시 표시
- 기존 보강 등록도 유효성 검사를 강화

## 휴강 후 흐름
휴강 후 다른 수업을 꼭 넣지 않아도 됨.
필요한 경우 주간 화면의 `+ 수업 추가`에서 언제든 따로 추가할 수 있음.

SQL 추가 없음.
